# 示例应用功能说明

## 页面

- `/` 首页：顶部导航含「首页」「计算器」「关于」三个链接；有「登录」按钮和「打开计算器」按钮。
- `/calc` 加法计算器：两个数字输入框，一个「计算」按钮。
- `/about` 关于页：显示版本信息。
- `/settings` 设置页：主题与偏好设置。

## 功能

- **加法计算**：在计算器页输入两个数字并点击「计算」，页面显示两数之和，例如输入 3 和 5 应显示"结果：8"。
- **深色模式**：设置页提供「深色模式」切换按钮，点击后整个站点变暗。
- **搜索**：首页顶部提供搜索框，输入关键词实时过滤页面内容。
- **CSV 导出**：计算器页有「导出 CSV」按钮，把历史计算记录下载为 csv 文件。
- **登录跳转**：在登录页提交表单后跳转到 `/dashboard` 显示欢迎语"欢迎回来"。
